# Visión artificial EcoBox

Al iniciar EcoBox MVC en Windows con el entorno `Development`, se abre también la aplicación Cámara de Windows. La cámara queda separada de la interfaz web. Mientras no exista un modelo entrenado, solo muestra una vista previa: no clasifica residuos, no guarda imágenes y no registra datos.

La integración de clasificación se realizará cuando se defina y agregue el modelo entrenado y su entorno de ejecución. No se asume un formato de modelo.
